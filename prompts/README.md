# prompts/

Standalone paste-in prompts — plain markdown, one task each. Not skills:
nothing here auto-loads or shows up as a slash command, so a file in this
folder costs nothing until someone deliberately pastes it into a session.

Reach for a prompt here instead of a skill when the task is judgment-heavy
but infrequent — a skill's `description` sits in every session's context
whether it's used or not (see [skills/README.md](../skills/README.md)),
which is the wrong trade for something run rarely.

Each file should be self-contained: what it's for, when to reach for it
instead of a skill, and the paste-in prompt itself in a fenced code
block.

Empty for now — add prompts as they're built and sanitized.
